# Awesome-Corporate-Governance-Platform

### Top Corporate Governance Platform Ecosystem

**Curated List of SaaS/Hosted Platforms & Open-Source GitHub Projects**  
*Focused on Board Management, Corporate Governance, Board Portals, Entity Governance, Meeting Management, Decision Management, Compliance & Governance Operations*  
**Last updated: August 2026**

This repository tracks notable **SaaS/Hosted Platforms** and **open-source projects** for **Corporate Governance Platforms**. These tools help boards of directors, corporate secretaries, general counsels, governance professionals, executives, and organizations manage board meetings, agendas, board books, minutes, resolutions, voting, approvals, action items, governance records, entity structures, compliance obligations, and secure board communications.

**Examples** include Diligent One, OnBoard, Board Intelligence, Convene, Boardable, Athennian, Diligent Entities, Governance.com, Aprio, and BoardPro.

Modern corporate governance platforms increasingly combine **secure board portals, digital board books, agenda management, meeting management, voting, minutes, decision registers, action tracking, e-signatures, entity management, compliance calendars, director evaluations, D&O questionnaires, governance workflows, AI meeting assistants, document intelligence, audit trails, and governance analytics**.

**Open-source emphasis**: The open-source ecosystem for dedicated corporate board-management software is considerably smaller than the commercial ecosystem. Therefore, this repository also includes strong open-source **governance, voting, decision-management, document-management, workflow, identity, audit-log, collaboration, and ERP building blocks** that can be combined to create a self-hosted corporate-governance platform.

The most directly relevant open-source projects include **OpenPR** for proposals, voting, governance workflows, decision records and audit trails, and **Votiverse** for locally runnable governance and voting systems. Other projects provide important components rather than complete board portals.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites or GitHub repositories.

## Open-Source GitHub Projects

> **Important:** There are relatively few mature open-source projects that directly replicate Diligent, OnBoard, BoardPro, or Convene as complete corporate board portals. The projects below therefore include both **direct governance platforms** and open-source infrastructure that can be assembled into a self-hosted corporate-governance system.

### Direct Governance / Decision Platforms

- **[OpenPR](https://github.com/openprx/openpr)**  
  Open-source project-management and governance platform with a dedicated governance center supporting proposals, configurable voting, decision records, audit logs, veto/escalation workflows, trust scores, AI agents, and MCP integration. It is one of the more directly relevant open-source projects for building governance workflows.

- **[Votiverse](https://github.com/votiverse/votiverse)**  
  Open governance and voting platform designed for locally runnable governance systems. It includes proposals, voting, delegations, surveys, candidacies, member management, authentication, and PostgreSQL/SQLite support.

- **[Loomio](https://github.com/loomio/loomio)**  
  Open-source collaborative decision-making platform supporting proposals, discussions, voting, decision records, and group governance.

- **[Decidim](https://github.com/decidim/decidim)**  
  Open-source participatory-democracy platform supporting proposals, consultations, meetings, voting, participation, and transparent decision-making.

- **[Consul Democracy](https://github.com/consuldemocracy/consuldemocracy)**  
  Open-source participation and decision-making platform with proposals, debates, voting, consultations, and participatory governance features.

- **[Pol.is](https://github.com/compdemocracy/polis)**  
  Open-source opinion and consensus platform useful for structured stakeholder input and governance decision processes.
